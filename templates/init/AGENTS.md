# Redash Queries and Dashboards

This directory holds Redash queries and dashboards for sql.telemetry.mozilla.org, managed with `stmo-cli`.

At the start of every session, run `stmo-cli guide` and follow its output. It holds the workflow and command reference for the installed CLI version, so this file does not need updating when the CLI changes.
